# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because the startup has a limited budget but expects rapid growth. AWS provides many services that can start with a small amount of resources and scale as the application gains more users. The company can use pay-as-you-go cloud resources instead of purchasing physical servers. AWS also provides many services that can support a mobile application's growth.

### Recommended Services

* Amazon EC2 – Virtual computing
* Amazon S3 – Object storage
* Amazon RDS – Managed relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure has strong integration with Microsoft technologies, making migration easier for the university's existing environment. The university can also connect its existing infrastructure to Azure using hybrid cloud capabilities. This can reduce the difficulty of moving Microsoft-based workloads to the cloud.

### Recommended Services

* Azure Virtual Machines – Cloud-based Windows or Linux servers
* Microsoft Entra ID – Identity and access management
* Azure Storage – Cloud storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is recommended because the company develops Artificial Intelligence and Machine Learning applications that require high-performance computing. Google Cloud provides specialized AI and machine learning services that can help researchers develop and deploy AI applications. It also provides powerful computing resources and Kubernetes capabilities for large workloads. These services make Google Cloud suitable for AI-focused research.

### Recommended Services

* Vertex AI – Artificial Intelligence and Machine Learning
* Compute Engine – High-performance virtual machines
* Google Kubernetes Engine – Kubernetes container management

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended because the company serves customers around the world and requires highly available infrastructure. AWS provides global infrastructure, automatic scaling, load balancing, and content delivery services. These capabilities can help the e-commerce platform handle changes in customer traffic while maintaining availability. AWS can also support databases, storage, security, and application hosting.

### Recommended Services

* Amazon EC2 – Application computing
* Elastic Load Balancing – Distributes traffic across servers
* Amazon S3 – Object storage
* Amazon CloudFront – Global content delivery
* Amazon RDS – Managed relational database
