## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works well with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft enterprise products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine and AI services such as Vertex AI.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a very wide range of cloud services and has a large global infrastructure. As an IT student, learning AWS can provide experience with computing, storage, networking, databases, and security.
