# Mission Reflection

During this laboratory activity, the cloud platform that impressed me the most was Amazon Web Services (AWS). I was impressed by the large number of services it provides and its ability to support different types of applications. AWS has services for computing, storage, databases, networking, security, and many other areas, making it useful for both small and large organizations.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, security services, and tools for application development. They also use a global infrastructure that allows organizations to deploy applications in different locations and scale their resources according to their needs.

Business requirements are very important when selecting a cloud platform. A company should consider its budget, existing technology, application requirements, security needs, performance, scalability, and future growth. For example, Azure is a good choice for an organization that already uses Microsoft technologies, while Google Cloud can be a strong choice for AI and Machine Learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The best choice depends on the specific problem that needs to be solved. I learned how to compare cloud services and connect technical features with actual business requirements.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I learned how to organize multiple Markdown documents, document technical research, include screenshots as evidence, and maintain a structured project folder. This activity also helped me become more comfortable with GitHub and improved my understanding of how cloud technologies can be evaluated and applied to real-world situations.
