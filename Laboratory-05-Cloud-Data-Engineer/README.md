# Laboratory Activity 05: Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud storage and object storage. I learned how Block Storage, File Storage, and Object Storage are different from each other.

For the practical part, I used Docker to run a MinIO-compatible object storage server. I then accessed the storage server through a web browser, created a bucket called `client-photos`, and uploaded a sample file.

## Objectives

The main objectives of this activity were:

- Learn the three common types of cloud storage.
- Compare Block, File, and Object Storage.
- Run an object storage server using Docker.
- Use environment variables in a Docker command.
- Access a service through port 9001.
- Create a storage bucket.
- Upload a file to the bucket.
- Document the work using Markdown.
- Improve my Linux and Docker skills.
